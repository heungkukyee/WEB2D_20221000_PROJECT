# 7주차 패키지 — Normal Map과 2D 입체감

6주차까지 완료한 프로젝트(Linear 색 공간 · 팔레트 테마 · 배경/캐릭터 조명 분리)에 임포트합니다.
모든 메뉴는 `CG2 Lab → 7주차`에 **수업 순서대로** 있고, Console에 `[실습]` `[분석]` `[측정]` `[검증]` 로그를 남깁니다.

## 메뉴 (위에서 아래로 누르면 수업 순서)

| 메뉴 | 어디서 | 하는 일 |
|---|---|---|
| `1-1. 실험 씬 열기` | 아무 씬 | 공(정답) · 기사 A(노멀 없음) · B(노멀 있음) · C(sRGB ON) · 벽돌 + 테스트 조명 |
| `1-2. 스프라이트 해부` | 실험 씬 | 스프라이트마다 메인 텍스처 · 보조 텍스처(_NormalMap) · 셰이더 표 |
| `1-3. 노멀 맵 색 읽기` | 어디서나 | 공 노멀 맵의 다섯 지점 RGB → 방향(X, Y, Z) |
| `1-4. 측정 #1` | 실험 씬 · **Play 중** | 빛 ← → 에서 좌우 밝기 · 입체감 점수 · sRGB 실수 |
| `1-5. 게임 씬으로 돌아가기` | 실험 씬 | 빌드 목록의 첫 씬을 연다 |
| `2-1. 측정 #2` | 게임 씬 | 노멀 맵 만드는 방법 3가지(밝기 · 외곽 · 혼합) 숫자 비교 + 비교 그림 |
| `2-2. 노멀 맵 스튜디오` | 게임 씬 | 플레이어 노멀 맵을 직접 만든다 (방법 · 세기 · 경사 · 디테일 · 미리보기 → `_n.png`) |
| `2-3. 나머지 한 번에 만들기` | 게임 씬 | 적 · 투사체 · 벽 · 바닥 노멀 맵 (캐릭터 = 혼합, 타일 = 밝기) |
| `3-1. 연결 검사 — 플레이어` | 게임 씬 | Sprite Editor에서 직접 연결한 뒤 검사 (이름 오타 · sRGB · 크기 · 필터) |
| `3-2. 나머지 한 번에 연결` | 게임 씬 | 나머지 그림 연결 + 전체 검사 표 |
| `4-1. 밤 장면 만들기` | 게임 씬 | 전역 조명 세기를 낮춘다 (배경 0.25 · 캐릭터 0.2) |
| `4-2. 테스트 조명 검사` | 게임 씬 | 직접 넣은 Spot Light 2D 설정 점검 + 마우스 따라가기 |
| `4-3. (비교) 노멀 맵 반응 끄기 ↔ 켜기` | 게임 씬 | 조명의 Normal Maps Disabled ↔ Accurate (Play 중엔 N 키) |
| `5-1. 측정 #3` | 게임 씬 · **Play 중** | 입체감(Disabled vs Accurate) · 비용(DrawCalls · SetPass · 렌더 텍스처) · 메모리 |
| `5-2. README 캡처` | 게임 씬 · **Play 중** | 노멀 맵 끄기/켜기 × 빛 ←/→ 4칸 그림 → `Captures/` |
| `5-3. 체크포인트` | 게임 씬 | 노멀 맵 · 조명 · 색 공간 · 측정 점검 |
| `되돌리기 — …` | | 실험 씬 다시 만들기 · 노멀 맵 연결 해제와 파일 삭제 · 조명 복구 |

## Play 중 테스트 조명 조작 (`CG2MouseLight`)

마우스 = 조명 이동 · **N** = 노멀 맵 반응 끄기/켜기 · **휠** = 조명 높이(Normal Map Distance)

## 실행하면 생기는 파일

`Lab/` 실험 씬과 그림 · `Captures/` 비교 그림 · 각 스프라이트 옆 `*_n.png` 노멀 맵 — 측정 기록은 `Library/CG2Week7/`(깃에 올라가지 않음)

## 주의

- 노멀 맵 파일을 **다시 저장(덮어쓰기)하면 스프라이트도 다시 임포트**해야 반영됩니다. 스튜디오 저장 버튼은 자동으로 합니다.
- Unity 6.6의 `GameObject → Light` 메뉴에는 Point Light 2D가 없습니다. **Spot Light 2D**를 만들면 360° 점 조명입니다.
- 새 조명의 `Normal Maps → Quality` 기본값은 **Disabled**입니다. 노멀 맵이 연결되어 있어도 이 값이 Disabled면 화면이 그대로입니다.
