# 6주차 패키지 — 색 공간과 아트 가이드

5주차까지 완료한 프로젝트(게임 맵 · 카메라 리그 · Canvas 3분리 · AI 에셋)에 임포트합니다.
모든 메뉴는 `CG2 Lab → 6주차`에 있고, Console에 `[검증]` / `[측정]` 로그를 남깁니다.

## 메뉴

| 단계 | 메뉴 | 하는 일 |
|---|---|---|
| 도입 | `2-0. 색 감사` | 지금 씬에 칠해진 색을 세고, 팔레트에서 나온 색인지 하드코딩인지 표시 |
| 1 | `1. 색 공간 실험 씬 열기` | 실험대 씬(회색 칸 · 라이트 겹침 · 반투명 · sRGB ON/OFF)을 만들고 연다 |
| 1 | `1-1. 측정` | 지점 10곳의 화면 출력 값(0~255)을 기록. 두 색 공간을 다 재면 나란히 비교 |
| 1 | `1-2. 색 공간 전환` | Gamma ↔ Linear (모든 텍스처 재임포트). **끝나면 Linear로 되돌린다** |
| 1 | `1-3. 게임 씬으로 돌아가기` | 빌드 목록의 첫 씬을 연다 |
| 2 | `2. 팔레트 스튜디오` | 기준색 + 조화 규칙 → 1·2·1 팔레트 생성 · 60:30:10 · 흑백/색약 · WCAG 검증 → `Palette/MyPalette.asset` |
| 5 | `2-1. 흑백·색약 미리보기 캡처` (Play 중) | 화면(Overlay UI 포함)을 원본 · 흑백 · 적록 색약 3칸 PNG로 저장 → `Captures/` |
| 3 | `3. UI 테마 적용` | 씬에 `CG2 Theme`을 놓고 버튼 5상태 · 패널 · 바를 팔레트로 칠한다. 처음 실행할 때 5주차 색을 `Backup/`에 기록 |
| 3 | `3-1. 한글 폰트 에셋 만들기` | 갈무리11(OFL)로 Dynamic TMP 폰트 에셋을 만들고 기본 폰트의 Fallback에 등록 |
| 3 | `3-2. 픽셀 폰트로 통일 · 고정 문구 한글화` | 씬의 모든 TMP 글자를 갈무리11로, 상점·닫기·다시 시작 문구를 한글로 |
| 3 | `3-3. (비교) 5주차 색 ↔ 테마` | 누를 때마다 5주차 색과 테마를 번갈아 |
| 4 | `4. 씬 톤 적용` | 전역 조명을 배경용(Ground·Wall)과 캐릭터용(`CG2 Entity Light`)으로 나누고, 배경 조명 · 카메라 배경 · Ground/Wall 타일맵 틴트를 팔레트로 |
| 4 | `4-1. 측정 — 틴트 방법별 배칭` (Play 중) | 적 스프라이트 100개 × 4가지 틴트 방법 × SRP Batcher ON/OFF |
| 4 | `4-2. 테마 바꾸기` | 프리셋(던전 · 밤의 숲 · 용암) 순환. **Play 중에는 T 키** |
| 4 | `4-3. 측정 #3 — 게임 전·후 비교` (Play 중) | 같은 프레임에서 5주차 상태 · 6주차 색 + 영문 폰트 · 6주차 상태를 번갈아 끼우고 렌더링 비용 · 가독성(명도 대비) · 화면 값을 기록. 다른 색 공간에서 한 번 더 실행하면 Linear ↔ Gamma 비교표 (수업에서는 교수자 시연) |
| 5 | `5. 아트 가이드 내보내기` | 적용된 값에서 `ArtGuide/ArtGuide.md` + `palette_swatch.png` 생성 |
| 6 | `6. 체크포인트` | 색 공간 · 팔레트 · UI · 폰트 · 씬 톤 · 측정 · 문서 점검 |
| — | `되돌리기 — 1단계 실험 씬 다시 만들기` | 실험 씬을 지우고 새로 만든다 |
| — | `되돌리기 — 3·4단계 테마 제거` | 5주차 색으로 복원 · 포커스 링과 캐릭터 조명 삭제 · 전역 조명을 다시 모든 레이어로 · `CG2 Theme` 삭제 (팔레트는 남김) |
| — | `되돌리기 — 3단계 폰트` | 기본 영문 폰트 · 영문 문구로 |
